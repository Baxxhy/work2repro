# 实际运行代码与环境补丁

- `controller/`：最终恢复控制器、作业进程、完成判定、评测证据复用、最终统计和完整性核验；包含离线回归测试。
- `req_agent.py`：在锁定官方 Req2Test 生成器外接入原模型服务，指定 gpt-6-luna / medium 和 JSON 轨迹。不更改官方任务提示词、200 次调用上限或文件收集边界。
- `diagnostic_eval.py`：调用官方 CLI；仅在独立 exec-only 诊断时保留完整 stdout，正式计分行仍由原函数生成。
- `patches/`：实跑环境差异、Dockerfile 和版本保持记录。
- `upstream-licenses/`：对应作者仓库 LICENSE 副本；作者代码通过锁定提交获取，不在这里混入其他版本。

这些文件是实跑快照，保留了 `/root/Baxxhy/work2` 和 `/root/lby-docker` 的目录依赖。认证只在实验机的根用户模型网关中处理，仓库不包含认证文件或有效密钥。控制器是恢复既有队列的工具；全新运行需要先准备官方仓库、完整数据、模型服务和自己的队列状态。不能直接以本轮已完成配置启动一个新实验。

运行步骤、输入范围、生成预算、评测协议及服务器来源详见 [复现报告](../../reports/test-generation-20261114/README.md)。
