# Coddy 官方评测并发与耗时核对

开始时间为北京时间 2026-11-17 09:58:15，完成记录于同日 09:58。

锁定源码 c0d7138f408bb7935d2c82e0fed82884f519b199 的 docs/environments.md、docs/evaluation.md 已核对，并查阅作者 GitHub 官方网页。

- 官方 Coddy 默认 K=40，单 worker 内存上限 16 GiB、禁用 swap。作者称默认池面向 64 CPU 主机，须按资源调整。内存上限代表允许的峰值，各 worker 实际用量需要实测。
- 官方支持 evaluate --workers K，以及分项目、多主机运行后汇总。
- docs/evaluation.md 成本表列出 Coddy 274 场景、56,539 个参考测试关联变异对。单次执行 98 秒，口径为单 worker 上带覆盖率的参考测试执行。
- 全基准一次完整配置约 1,000 worker-hours，主要耗在 Coddy 与 Kapua。该值为各 worker 工作时间之和，不能当作并行后的自然耗时。
- 当前生成测试对应 Coddy 10,869 对。最近 30 个新执行变异对的 seconds 中位数 121.23 秒，最近五对为 123.79、121.20、123.02、120.59、119.06 秒。
- 官方 98 秒与本轮 121 秒测试内容、阶段不同，不能据此精确计算性能差异。当前数据支持单对执行为分钟级。
- 当前只开 1 个 Coddy worker，源于此前隔离故障后的保守恢复配置。按剩余约 9,500 对乘约 121 秒，单路约 13 天。该值为当前单路外推，未考虑并发与任务耗时变化。
- 当前遵循官方逐变异执行和计分流程，没有额外生成测试。完整变异开销来自官方评测路径。源码支持 --metrics exec 跳过变异，但该模式不产生 KillComplete 和 Mutation R，因此不能替代本轮完整评测。
- 本轮只核对与解释现状，运行中的池保持当前配置。
