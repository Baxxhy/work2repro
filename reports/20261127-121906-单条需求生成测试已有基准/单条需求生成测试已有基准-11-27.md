# 单条自然语言输入生成可执行测试的已有数据

核查范围为代表性一手公开材料，按输入的来源、测试单位与执行判据选择。此次只查文献及数据说明，没有下载并运行实验。

| 数据或方法 | 一条输入及对应输出 | 可回答的问题 |
|---|---|---|
| PyTester 的 APPS 设置，2024 年公开预印本，2025 年发表于 JSS | 编程题文字描述和调用接口生成 Python 测试；一道题允许有多条用例 | 函数或编程题级自然语言到测试。作者提供处理后的训练集、测试集和方法。[论文](https://arxiv.org/abs/2401.07576) · [仓库](https://github.com/awsm-research/pytester) |
| SWT-Bench，NeurIPS 2024 | GitHub issue 与当时仓库生成测试补丁，验证修复前失败、修复后通过 | 仓库级开发者问题描述到回归测试。一条 issue 可以产生多个测试函数。[论文](https://proceedings.neurips.cc/paper_files/paper/2024/hash/94f093b41fc2666376fb1f667fe282f3-Abstract-Conference.html) |
| Sakura，ISSTA 2026 | 20 个 Apache 项目中 488 个开发者测试，各对应 3 个抽象程度的自然语言描述，共 1,464 个描述与测试配对 | 单条场景描述到一个具体 Java 测试。文字从已有测试反推，不能当作原始产品需求。论文报告编译、覆盖等指标。[作者论文](https://arxiv.org/html/2606.00530v3) · [仓库](https://github.com/aster-test-generation/sakura) |
| GivenWhenThen，MSR 2026 | 作者报告 2,289 条 BDD 记录，将 feature 文件关联到步骤定义和系统代码 | 可研究真实项目已有文字场景与实现的对应。使用时需核实文件内的场景和共享步骤，论文与归档提供配对材料。[数据](https://zenodo.org/records/17573782) · [论文](https://aserg.labsoft.dcc.ufmg.br/assets/papers/2026-msr-gwt.pdf) |
| Req2Test | 一条开发者编写的 Gherkin 行为场景对应一份可能跨文件的测试实现。共 5,086 条，eval 为 2,051 条 | 在仓库中执行生成测试，评价能否通过及检出变异。输入已经具体到场景，不能泛化为从整条宽泛产品需求自动发现所有测试场景。[论文](https://arxiv.org/abs/2610.36584) |

早期工作还包括 SCAM 2019 的 Behave Nicely!，它从 Gherkin 的单步描述生成步骤函数；可用于回溯研究历史，和整场景生成的任务粒度不同。[论文](https://eprints.gla.ac.uk/192036/)

筛选建议：若问题是给一条不含测试步骤的功能要求，让模型选择输入并写出断言，先看 PyTester 的 APPS 设置；若要现成的一段描述对应一个仓库测试，先看 Sakura；若要项目原有的行为场景和可执行的行为充分性评分，先看 Req2Test。对于自由表述的真实产品需求、人工一一配对和仓库级可执行评分三个条件，本次资料不足以认定其中任何一个同时满足。
